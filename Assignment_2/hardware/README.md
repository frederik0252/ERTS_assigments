# Exercise 7 Vivado hardware

This directory contains the migrated Vivado 2026.1 project for the ZYBO
XC7Z010. The build script uses the neural-network IP generated by
`../exercise7_neural_net/hls/run_hls.tcl`, upgrades the legacy block design,
repairs the switch/LED connections, connects both AXI4-Lite interfaces, applies
the ZYBO pin constraints, and generates a bitstream and XSA.

Generate and export the HLS IP first:

```sh
source ~/AMD/2026.1/Vitis/settings64.sh
cd Assignment_2/exercise7_neural_net/hls
vitis-run --mode hls --tcl run_hls.tcl
```

```sh
source ~/AMD/2026.1/Vivado/settings64.sh
cd Assignment_2/hardware
vivado -mode batch -source build_ex7_2026.tcl
vivado -mode batch -source program_ex7.tcl
```

Generated outputs:

- Bitstream: `Ex7/Ex7.runs/impl_1/system_wrapper.bit`
- Hardware platform: `Ex7_2026_1.xsa`
- Timing report: `ex7_timing_summary.rpt`
- Utilization report: `ex7_utilization.rpt`

Build the Exercise 7 bare-metal application natively with Vitis 2026.1:

```sh
source ~/AMD/2026.1/Vitis/settings64.sh
vitis -s ../exercise7_neural_net/sdk/build_vitis_2026.py
```

This recreates the Vitis workspace at `Ex7_vitis`, generates the standalone
Cortex-A9 platform and BSP from the XSA, and produces the application at
`Ex7_vitis/neuralNetTest/build/neuralNetTest.elf`.

With `hw_server` running and the ZYBO UART configured for 115200 baud, program
the bitstream, initialize the processing system, download the ELF, and run it:

```sh
source ~/AMD/2026.1/Vitis/settings64.sh
xsdb run_ex7_on_board.tcl
```

The 10 October 2026 build completed implementation and bitstream generation,
met timing with WNS 3.462 ns, and was programmed to `xc7z010_1` with DONE=1.
The physical target run returned `Overall verification: PASS`; CPU compute,
AXI loading, and accelerator compute measured 186,751, 233,860, and 21,697 SCU
timer ticks respectively.
